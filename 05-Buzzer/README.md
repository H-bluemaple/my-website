# Arduino 蜂鸣器实验记录（有源 / 无源对比与扩展）

记录一次蜂鸣器入门实验：对比有源与无源蜂鸣器的控制方式，并完成两项扩展（救护车滑音、小星星旋律）。  
该实验为阶段性接触学习；下一步将进入后续教程实验。

---

## 一、实验器材与原理

### 1. 实验器材
- Arduino UNO 开发板  
- 两脚蜂鸣器 ×2  
  - TMB12A05（有源蜂鸣器，测试用）  
  - 无标识开孔型（无源蜂鸣器，测试用）  
- 杜邦线若干  

注：本实验使用两脚裸元件，而非三针模块版本。

### 2. 蜂鸣器类型与发声原理

#### 有源蜂鸣器（Active Buzzer）
- 内部带振荡电路  
- 只要供电就能自行振荡发声  
- 音调（频率）基本固定  

结论：Arduino 只能控制“响 / 停”和节奏，无法改变音高。

#### 无源蜂鸣器（Passive Buzzer）
- 内部不带振荡电路  
- 需要外部方波驱动才能发声  
- 可通过改变方波频率改变音高  

结论：Arduino 可通过输出不同频率的方波来控制音调。

## 二、接线方式

- 蜂鸣器一脚 → Arduino D9  
- 蜂鸣器另一脚 → GND  
- 若蜂鸣器标有 “+”，则 “+” 接 D9

## 三、实验内容（4 个小实验）

### 01 有源蜂鸣器基础发声（01_active_basic）
现象：
- `digitalWrite(HIGH)` 后持续发出稳定“滴——”声  
- 用 `delay()` 控制 HIGH/LOW，只能改变节奏（滴滴滴），音调不变  

结论：
- 有源蜂鸣器“供电即响”，频率不可调  
- 代码重点在“开 / 关 + 时长”

---

### 02 无源蜂鸣器频率测试（02_passive_basic）
做法：
- 使用 `tone(pin, freq)` 输出不同频率方波（如 50Hz、500Hz、2000Hz、4000Hz）  
- 每个频率持续一段时间，再切换到下一个频率

现象：
- 频率越高，声音越尖锐  
- 高频区更刺耳、更响  
- 低频听感更沉、更“嗡”

理解：
- `tone(pin, freq)` 的 `freq` 表示输出方波的频率  
- 人耳通常将方波的“基频”作为主音高来感知，因此输出频率基本对应听到的音高

---

### 03 扩展：救护车滑音（03_siren_glissando）
初始问题：
- 两个固定频率来回切换会显得“跳变”、不自然

改进方法：
- 用 `for` 循环逐步改变频率（连续变频），形成滑音

现象：
- 声音连续上升与下降，更接近救护车/警笛的效果  
- `delay()` 越小，变化越快，会显得更急促；`delay()` 稍大更平滑

理解：
- 滑音本质：频率不是“跳”，而是“连续变化”

---

### 04 扩展：小星星旋律（04_little_star）
初始问题：
- 连续音符听起来像少数几个音，尤其是相同音高连续时会融合成“一个长音”

原因：
- 相同频率如果无停顿，人耳会把它当作同一个持续音

解决方法：
- 每个音符结束后 `noTone()` 并加入一个很短停顿（休止）

理解：
- 音乐播放需要控制三件事：  
  - **频率**（音高）  
  - **时长**（音符持续时间）  
  - **休止**（音符之间的短暂停顿，用于分隔）

---

## 四、阶段总结

- 有源蜂鸣器：供电即响，音调不可调，只能改节奏  
- 无源蜂鸣器：需外部方波驱动，可用 `tone()` 改变频率控制音调  
- 滑音：通过连续变频（for 循环逐步改变频率）实现  
- 旋律：音符之间必须加入短暂停顿，否则重复音会融合  
- `tone()` 输出的方波频率基本对应听到的音高（以基频为主）

本阶段完成对蜂鸣器控制方式的基础理解与两项扩展实现，暂不继续扩展。
