# 实验 04：一位数码管显示（共阴极）

## 实验概述

本实验使用 Arduino UNO 驱动一位共阴极数码管，在**不依赖任何显示库**的前提下，
通过明确的段位映射与函数化控制，实现 0–9 数字的稳定显示。

实验重点不在“记住哪一段亮”，而在于：
- 从 **电流回路** 的角度理解 HIGH / LOW 的物理意义  
- 建立 **Arduino 引脚 ↔ 数码管段位** 的清晰映射  
- 通过 **最小验证 → 逐步扩展** 的方式完成系统构建  

---

## 硬件与基础说明

### 使用器件

- Arduino UNO
- 一位数码管（型号：4205SWB，共阴极）
- 面包板
- 跳线若干
- 电阻：1 kΩ × 若干

### 共阴极数码管说明

本实验使用 **共阴极数码管**，其工作特性为：

- 公共端接 **GND**
- 某一段点亮的条件是：  
  **对应段引脚为 HIGH，且形成从 Arduino → LED → GND 的电流回路**

因此：

> HIGH / LOW 并不等价于“亮 / 灭”，  
> 而是 **是否提供足够电位差以形成电流通路**。

---

## 器件层级映射（数码管 ↔ Arduino）

在实验中，首先完成的是**器件本身的结构识别**，
即明确「数码管每一个物理引脚」对应的「发光段位」。

本映射与 Arduino 接线方式无关，
属于**器件固有属性**，对同型号数码管恒成立。

### 数码管物理引脚定义（正面观察）

- 上排从左到右：1 – 5  
- 下排从左到右：6 – 10  

其中：

- **3、8 为公共端（共阴极）**
- **10 为小数点（dp）**

### 数码管引脚 ↔ 发光段 对应关系

| 数码管引脚 | 发光段位 |
|-----------|----------|
| 1 | 中横（g） |
| 2 | 左上竖（f） |
| 3 | 公共端（GND） |
| 4 | 上横（a） |
| 5 | 右上竖（b） |
| 6 | 左下竖（e） |
| 7 | 下横（d） |
| 8 | 公共端（GND） |
| 9 | 右下竖（c） |
| 10 | 小数点（dp） |

> 注：以上映射来源于**逐段点亮实测验证**，
而非商家文档或默认假设。

---

### Arduino 引脚映射策略（实验选择）

在确认器件层级映射后，
本实验采用“顺序映射法”连接 Arduino：

| 段位 | Arduino 引脚 |
|----|-------------|
| a | D2 |
| b | D3 |
| c | D4 |
| d | D5 |
| e | D6 |
| f | D7 |
| g | D8 |
| dp | D9 |
| 公共端 | GND |

该映射方式的目的在于建立：

> **Arduino 引脚编号顺序 ≈ 段位逻辑顺序**

从而降低后续代码编写与调试的认知负担。


## 最小验证策略

在完成接线后，并未直接尝试显示完整数字，
而是采用以下逐步验证流程：

1. **单段点亮测试**  
   逐一验证 a–g 各段是否能独立点亮
2. **全段点亮测试（显示 8）**  
   用于快速确认接线与公共端无误
3. **函数化扩展**  
   将每一个数字的显示过程封装为独立函数

这种“最小可行验证”的方式，是硬件排错中效率最高的策略之一。

---

## 数字显示的函数化设计

### 设计原则

每一个数字 `showX()` 函数均遵循统一结构：

1. 调用 `allOff()` 清空所有段位（避免残留状态）
2. 将该数字所需的段位设置为 `HIGH`
3. **不在函数内部引入 delay**
   - 显示节奏统一由 `loop()` 控制

### 示例说明

- `show0()` 点亮 a b c d e f
- `show1()` 点亮 b c
- `show8()` 点亮 a b c d e f g

通过这种方式：

- 显示逻辑与时间控制解耦
- 每个数字的实现清晰、可独立验证
- 后续可自然扩展为数组映射或查表法

---

## 实验结果

在当前配置下：

- 数码管可稳定循环显示 **0–9**
- 各数字段位显示正确，无串扰
- 显示逻辑与接线映射保持一致

---

## 实验总结

- HIGH / LOW 表示的是**电位状态**，而非“亮 / 灭”
- 教程并非权威，应回到 **电流回路本身**进行分析
- “最小验证（单段点亮）”是最高效的硬件排查方法
- 清晰的映射关系是后续代码可维护性的基础
